What People Can See

Information is disclosed in stages, not all at once.

Before A Match

Visible: event, general area, seats needed, transportation note, limited identity.

Hidden: exact address, phone, email.

After Confirmation

Visible: only details necessary to complete the ride.

Phone/email remain hidden when the owner chooses relay-only contact.

During The Ride

Status changes are manual: On My Way, Picked Up, Dropped Off, Arrival Confirmed.

No GPS, route, speed, or vehicle tracking.

After The Ride

Precise information is minimized and retained only according to policy. Users can export or request deletion of personal data.

Install BandWagon

Use it like an app without an App Store download.

iPhone / iPad

Open BandWagon in Safari → Share → Add to Home Screen → turn on Open as Web App if shown → Add.

Android

Open BandWagon in Chrome → menu → Install app / Install and create shortcut → Install.

Installing BandWagon does not enable GPS tracking. The same service remains available in a normal browser.
