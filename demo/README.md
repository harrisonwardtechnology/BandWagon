# FloMoGo Interactive Demo

FloMoGo is the first community service powered by **BandWagon**, an open-source Harrison Ward Technology product.

This demo uses fake data only. It creates no real rides and uses no Twilio, SMTP, Google Maps, Google Calendar, Microsoft Graph or production database credentials.

## Coolify

Deploy this directory as a separate application using the included Dockerfile. No environment variables are required.

## PWA

The demo includes a web manifest and an Install App help dialog. Production BandWagon should add organization-aware icons and a service worker with conservative caching rules.
