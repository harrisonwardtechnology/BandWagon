# Security Policy

BandWagon is a privacy-focused community coordination platform maintained by Harrison Ward Technology.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the security contact configured for the deployment. Do not include unnecessary personal information in a report.

Please do not publicly disclose a vulnerability before the maintainer has had a reasonable opportunity to investigate and remediate it.

## Sensitive data

Do not submit real passwords, access tokens, OTPs, precise home addresses, or private information about minors in public GitHub issues.
