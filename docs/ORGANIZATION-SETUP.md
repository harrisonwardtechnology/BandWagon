# Organization Setup

1. Open BandWagon and choose **Register an Organization**.
2. Enter organization name/type, city/state, optional website and primary admin contact.
3. Verify the admin email.
4. Choose discoverability: Public, Unlisted or Invitation Only.
5. Create groups such as Marching Band, Guard or Percussion.
6. Choose membership policy: code immediate, code + approval, or invitation only.
7. Configure driver rules, including minimum age and whether student drivers are allowed.
8. Configure household/minor approval defaults.
9. Configure custom/recurring rides, visibility, reminders, escalation and no-show handling.
10. Connect one or more **Google Calendar** and/or **Microsoft 365/Outlook** calendars using read-only access; map each calendar to groups.
11. Confirm calendar sync health and imported events.
12. Customize branding and welcome text.
13. Optionally configure and verify a custom domain.
14. Generate expiring/revocable registration codes or invitations.
15. Add a second organization admin for continuity.
16. Review Trust/Privacy/Terms pages.
17. Run a test ride before opening the community.

## FloMoGo baseline

- Service: FloMoGo
- Tagline: Hop on the BandWagon.
- Primary domain: flomogo.app
- Email verification: required
- Contact details: hidden by default
- Tracking: none
- Round trips: enabled as separate linked legs
- Custom rides: enabled
- Parent approval: household-configurable
